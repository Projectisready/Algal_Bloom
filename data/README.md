# Data

The dataset used in this project is not redistributed in this repository.

Download the U.S. EPA dataset:

**Predictions of Cyanobacteria and Microcystin in Lakes across the
Conterminous United States**

DOI: 10.23719/1532353

For this analysis, download:

- `HABsDrivers_Model_Data.csv`
- `HABsDrivers_Model_Metadata.csv`

Place both files in this `data/` directory before running the notebooks.
